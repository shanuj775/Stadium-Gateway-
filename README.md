# StadiumGateway 🏟️

StadiumGateway is a premium, real-time stadium management and ticketing dashboard designed to enhance the fan experience. It provides live traffic updates, smart routing, seat booking, and community engagement features—all wrapped in a stunning modern interface.

[![Live Demo](https://img.shields.io/badge/Live-Demo-10B981?style=for-the-badge)](https://stadiumgateway.vercel.app)

---

## ✨ Key Features

### 🌍 Global Localization (Multi-Language)
- Full support for **English** and **Hindi** across all interfaces.
*   **Smart Translation Engine:** Dynamically translates content, placeholders, and even live safety broadcasts.

### 🚗 Smart Traffic & Logistics
*   **Live Gate Traffic:** Real-time monitoring of stadium entrance congestion (Clear, Busy, Heavy).
*   **Smart Routing Advisory:** Recommends the most efficient path to your seat based on live crowd data.
*   **Parking Info:** Integrated parking status for specific stadiums.

### 🎟️ Premium Ticketing System
*   **Interactive Stadium Map:** Visual layout of stands (North, East, West, South).
*   **Real-time Seat Booking:** Select and reserve seats with live availability indicators.
*   **Parking Add-on:** Option to book parking directly during the ticket purchase flow.

### 🏏 Live Fan Experience
*   **Real-time Scorecard:** Live cricket match updates (Scores, Overs, Run Rate) integrated into the dashboard.
*   **Fan Zone:** Global chat for fans to interact during matches.
*   **Mini-Games:** Interactive Reflex Catcher game to earn fan rewards.
*   **Stadium Shop:** Premium merchandise and express food pickup ordering.

### 🛠️ Admin & User Portals
*   **User Dashboard:** Track points, view booking history, and report gate congestion.
*   **Admin Center:** Manage system logs and monitor live stadium analytics.

## 🎨 Design Aesthetics
*   **Glassmorphism:** A premium frosted-glass UI with subtle blurs and borders.
*   **Dark/Light Mode:** Seamless theme switching with persistent user preferences.
*   **Micro-Animations:** Smooth transitions, hover glows, and live pulse indicators for a "living" UI.
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.

---

## 🚀 Tech Stack
- **Frontend:** Vanilla HTML5, CSS3 (Custom Variables & Animations), JavaScript (ES6+).
- **Icons:** FontAwesome 6.4.0.
- **Typography:** Google Fonts (Outfit).
- **Hosting:** Vercel (Auto-deploy via GitHub).
